# Pattern Problems 🔷

This folder contains my pattern-solving practice as part of my DSA journey.

The main goal of these problems is to improve **logical thinking, nested loops, and problem-solving skills** before moving on to more advanced Data Structures and Algorithms.

## 📚 Topics Practiced

- Star Patterns
- Number Patterns
- Character Patterns
- Pyramid Patterns
- Symmetric Patterns
- Hollow Patterns
- Nested Loop Practice

## 🧠 What I am Learning

Through these problems, I am practicing how to:

- Understand a pattern row by row
- Identify the relationship between rows and columns
- Use nested loops effectively
- Calculate spaces and characters
- Build symmetric and geometric patterns
- Convert a visual pattern into program logic
